# -Sales-Data-Analysis-Project-Python-Pandas-
📌 Project Overview  This project analyzes a sales dataset using Python and Pandas to extract meaningful business insights. The analysis focuses on sales performance, profit trends, regional performance, discount patterns, and time-based sales growth.
 The goal is to answer key business questions using data analysis techniques.

⸻

**🛠 Tools & Technologies Used
	•	Python
	•	Pandas
	•	NumPy
	•	Matplotlib
	•	Google Colab / Jupyter Notebook
	•	GitHub

⸻

**📂 Dataset Description

The dataset contains sales transaction records including:
	•	Order ID
	•	Order Date
	•	Region
	•	Category
	•	Sub-Category
	•	Sales
	•	Profit
	•	Quantity
	•	Discount
** 📈 Key Insights
	•	The highest performing category is (insert result here).
	•	The region generating the highest profit is (insert result here).
	•	Sales show a (increasing/decreasing/stable) trend over time.
	•	Discounts significantly impact profitability in certain regions.
